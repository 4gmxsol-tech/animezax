# AnimeZax

**Anime discovery, watch guides, reviews, and anime culture.**

AnimeZax is an independent editorial project helping fans discover their next anime. The site is a lightweight static website designed for GitHub Pages and a custom domain.

## Project structure

- `index.html` — homepage and discovery sections
- `assets/styles.css` — responsive visual design
- `assets/script.js` — search, genre filters, and mobile navigation
- `assets/favicon.svg` — site icon

## Local preview

Open `index.html` in a browser. No build step or package installation is required.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

When ready to connect the custom domain, add `animezax.com` in the Pages custom-domain field and configure the DNS records at the domain registrar. Enable HTTPS once GitHub Pages makes it available.

## Editorial and rights note

AnimeZax is an independent fan discovery and editorial project and is not affiliated with anime studios, publishers, or rights holders. Use original writing and properly licensed or permissioned media. Link to official viewing sources rather than hosting copyrighted episodes.

## Monetization

Advertising is a future step. Add ad code only after the site is ready and the advertising provider has approved it. Do not use automated, incentivized, or otherwise invalid traffic.
