WATCH ORDER

Death Note watch order.

Death Note has a straightforward first-watch path: the main 37-episode television series in order, with compilation films treated as optional extras.

Recommended order

1. Death Note

Watch the 37-episode television series from episode one through the finale.

2. Recap films

The compilation films are optional and mainly useful as alternate summaries rather than replacements for the full series.

Quick advice

For a first viewing, use the main television series in release order unless an official release or licensed platform presents a different intended sequence. Avoid skipping canon episodes simply because a list labels them as optional without checking the context.
